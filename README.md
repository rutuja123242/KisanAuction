# KisanAuction

Project Description

Small farmers often struggle to find reliable buyers and secure fair prices for their produce. At the same time, larger supply chain owners and big buyers face challenges in sourcing quality agricultural goods directly from farmers. This platform aims to bridge this gap by connecting small farmers with both local buyers and big supply chain owners. Through a digital marketplace, farmers can directly showcase their goods, while buyers can place bids, ensuring competitive prices.

Features

Map-based farm location visibility
WhatsApp URL integration for bid acceptance notifications
Live crop auction system
Bid tracking and history
Time-bound auctions
Direct farmer–buyer interaction
Transparent and fair price discovery
Easy crop listing with images and details

Tech Stack

- Frontend :  HTML , CSS, Javascript
- Backend : Firebase(Auth , Realtime DB , Hosting )
